RevMan 5.4 非 Cochrane 模式
建库与 Meta 分析操作指引

面向未加入 Cochrane 协作网、仅需在本地独立完成系统评价 / Meta 分析的研究者。全文按软件真实界面术语编写，从首次启动到导出森林图逐步讲解。

软件版本：Review Manager 5.4.1 适用系统：macOS（含 Apple 芯片） 模式：non-Cochrane（离线本地） 预计通读 + 实操：约 60–90 分钟
关于「非 Cochrane 模式」：它是 RevMan 5 内置的一种本地工作模式，无需 Cochrane 账号或机构许可，所有数据保存在本机的 .rm5 文件中，可正常完成数据录入、Meta 计算与图形输出。代价是：不能向 Cochrane Library 提交、无在线协作与模板库。对于撰写普通（非 Cochrane）系统评价，本模式完全够用。

00首次启动与模式设置约 5 分钟

第一次打开软件时，需要依次处理三个弹窗。这一步决定后续能否离线顺畅使用。

1

启动软件。在 /Applications/RevMan/Review Manager 5.4.app 双击打开；首次加载 Java 运行环境较慢，等待数秒属正常。

2

Usage mode（使用模式）对话框 → 选择 “non-Cochrane mode”。

只有首次启动才会出现。两个选项的含义：

  • Cochrane mode：需注册账号与许可证、连接 Cochrane 服务器——本场景不选。
  • non-Cochrane mode：本地离线使用，无需登录——选择此项。
3

Update Available（更新提示）→ 选择 “No / 暂不更新”。当前网络无法访问 Cochrane 更新服务器，跳过即可，不影响任何本地功能。

4

Welcome to Review Manager 5 界面 → 点击 “Create a new review”。进入新建向导（详见第 02 节）。

建议 · 切换中文界面 菜单 Tools › Preferences，在 General / Interface 选项卡中找到 Language 下拉框，选择 Chinese (Simplified)，保存后重启软件即全面汉化。本指引保留英文术语，便于对照原始界面与英文文献。
Mac 操作提示 手册中的“右键”在 Mac 上为 Control+单击，或触控板双指点按；如需右键菜单，请以此方式操作。

01工作流总览约 2 分钟

建库本质是沿着左侧大纲树自上而下填充内容。核心链路只有一条，记住这条主线即可：

核心原则 「研究（Study）」必须先进入 Included studies，才能在「比较—结局」中被勾选用于分析；「结局（Outcome）」的数据类型一旦选定并录入数据，中途更换数据类型会清空已录数据。因此建议先定好分析框架再录数。

02新建综述文件约 5 分钟

通过 New Review Wizard（新建综述向导）建立文件骨架。

1

菜单 File › New，或点击工具栏 New 按钮，打开 New Review Wizard。

2

选择综述类型。常用四种，按需选择：

类型适用场景
Intervention review 干预性综述最常用。比较两种干预（如封堵器 vs 药物），二分类 / 连续变量 Meta 分析均选此项。
Diagnostic test accuracy 诊断准确性评价某诊断试验的敏感度、特异度等。
Methodology review 方法学综述研究方法学问题。
Overview of reviews 综述的综述对已有系统评价再综合。
3

填写 Title（标题）、Authors（作者）等基本信息，这些信息会用于文内与导出图表的引用。

4

选择 Full review（完整综述），不要选 Protocol。Proto­col（方案）状态下统计计算功能不可用，无法生成森林图。

5

点击 Finish，得到一个带完整章节骨架的综述文件。

注意 在 RevMan 内新建的综述并非 Cochrane 官方模板，日后不能不经大量改写就直接投稿为 Cochrane Review。这一点对非 Cochrane 模式的普通系统评价无影响。

03认识主界面约 3 分钟

打开文件后为三栏式布局，后续所有操作都围绕左侧大纲树展开。

① 顶部菜单栏

  • File：新建 / 打开 / 保存 / 导入导出
  • Edit、View、Tools：偏好设置等
  • Help：内置手册、教程、计算器

② 左侧大纲面板（Outline）

  • 树状结构：Main Text、Tables、Studies and references、Data and analyses、Figures 等
  • 点小钥匙图标展开下级；右键节点弹出新增菜单

③ 中部内容面板（Content）

  • 显示当前选中章节的正文或数据表
  • 数据表标签内可粘贴数据，森林图实时联动更新

④ 常用工具栏按钮

  • Add（绿色 +）：新增节点
  • Edit Outcome：打开结局数据表
  • Forest Plot：弹出森林图窗口
  • Funnel Plot：漏斗图
正文区结构 Main Text 下的 Background、Objectives、Methods、Results、Discussion 等章节是系统评价的撰写框架，可直接在右侧填写文字；它们与统计分析相互独立，但结果章节可一键插入分析产生的数值与图。

04录入纳入研究约 10–20 分钟

先把所有纳入研究的“身份”建好，后续分析才能引用它们。

1

在左侧依次展开 Studies and references › References to studies › Included studies。

2

右键点击 Included studies，选择 Add Study，打开 New Study Wizard。

3

填写 Study ID，命名规则为「第一作者姓氏 + 发表年份」，如 Liu 2021、Zhang 2023。点 Next 可补充来源、年份等完整信息，直接 Finish 亦可。

4

重复添加全部研究。若点 Next 到最后一步，勾选 Add another study in the same section 可连续录入多篇。

5

（可选）从 EndNote 等文献管理器导出 RIS 后批量导入：right-click References to studies › Import References。

命名一致性 Study ID 一旦确定，全文（数据表、森林图、偏倚图）统一引用该 ID。建议提前在 Excel 中固定好研究清单与顺序，避免后期“张冠李戴”。

05构建比较与结局约 15–25 分钟

这是决定统计分析框架的关键一步：先建“比较”，再在比较下建“结局”，结构最多三层（比较 → 结局 → 亚组）。

5.1 添加比较 Comparison

1

右键左侧 Data and analyses → Add Comparison → 输入名称（如 Occluder vs Control）→ Finish。

5.2 添加结局 Outcome

2

右键刚建好的比较 → Add Outcome，打开 New Outcome Wizard。

3

选数据类型（Data type）：

类型含义 / 需准备的数据举例
Dichotomous 二分类每组的事件数 + 总人数死亡/存活、发生/未发生并发症
Continuous 连续每组的均数 + 标准差 + 例数血压、评分、随访时间
O-E and Variance已算好的观察−期望值及方差从生存曲线提取
Generic Inverse Variance已算好的效应量及其标准误文献直接报告 HR 及 95%CI
Other Data自由文本表格无法进行 Meta 的展示性数据
4

依次填写 Name（结局名称） → Group Labels（组标签，默认 Experimental / Control） → Analysis Method（统计方法、模型、效应量） → Analysis Details → Graph details → Finish。

5.3 关键设置对照

设置项二分类结局连续型结局
Statistical Method
统计方法		Mantel-Haenszel（最常用）Inverse Variance
Effect Measure
效应量		RR 风险比 / OR 比值比 / RD 风险差MD 均数差 / SMD 标准化均数差
Analysis Model
分析模型		Fixed effect 固定效应；Random effects 随机效应（异质性较大时选用）
Graph Label
森林图横轴标签		Left / Right Graph Label，默认 “Favours experimental / Favours control”。若“事件发生”代表有利结局，务必将左右标签对调，否则森林图方向解读会出错。
高频错误 当结局是“有利事件”（如缓解、成功封堵）时，须把横轴左侧改为 Favours control、右侧改为 Favours experimental；沿用默认标签会使图形方向与实际结论相反。
亚组 如需预设亚组分析，右键某个 outcome → Add Subgroup，再把研究加入亚组。注意：一个结局下“要么直接挂研究，要么挂亚组”，二者不可并存；已挂研究时可用 Introduce Subgroup 转换。

06添加并录入数据约 15–30 分钟

两步走：先把研究“挂”到结局下，再从 Excel 整块粘贴数据。

6.1 把研究加入分析

1

右键 outcome（或 subgroup）→ Add Study Data → 在 New Study Data Wizard 中勾选需要的研究 → Finish。

2

点击该 outcome，再点工具栏 Edit Outcome，打开数据表标签（Data table）；表中已列出刚勾选的研究，右侧森林图随录入实时更新。

6.2 Excel 数据准备与粘贴

3

在 Excel 中按下列严格列序整理（每行一项研究，顺序与 RevMan 数据表一致）：

二分类（Dichotomous）连续型（Continuous）
Study｜E1 事件｜N1 总数｜E2 事件｜N2 总数 Study｜Mean1｜SD1｜N1｜Mean2｜SD2｜N2

1 = 试验组（Experimental），2 = 对照组（Control）。切勿把实验组与对照组列序颠倒，或把 SD 与 N 错位。

4

在 Excel 选中数据区域复制 → 回到 RevMan 数据表，点击目标区域左上角单元格 → 工具栏 Paste（或右键 Paste）。数据即整块填入。

5

若原始文献只报告中位数与四分位距或样本量不均衡，可用菜单 Tools › Calculate data（计算器）估算均数与标准差，再填入；绿色单元格表示输入有效，红色表示有误。

数据完整性红线 所有数值必须来自纳入文献原文，禁止为使结果“更好看”而编造、篡改或选择性剔除数据；由中位数推算或任何近似处理须在 Methods 中明确标注为“估算”；敏感性分析等探索性结果也须如实标注。这是科研诚信与投稿审稿的底线要求。
零事件怎么办 某组事件数为 0 时无需自行校正，RevMan 会按统计方法自动处理（必要时可查看 Analysis Details 中的相关选项）。

07生成与导出森林图约 10 分钟

数据表录入的同时森林图已在右侧生成，下面看细节调整与导出。

1

在 outcome 数据表标签点击 Forest Plot 按钮，图形在独立窗口打开。

2

调整横轴刻度：拖动图下方的滑块（scale slider）。若某研究的可信区间超出坐标范围，图中会出现箭头，此时向右拉伸刻度直至箭头消失。

3

核查统计输出：图下方给出合并效应量及 95%CI、I²（异质性）、Z 检验与 P 值。I² > 50% 通常提示中高度异质性，应改选随机效应模型或做亚组 / 敏感性分析，并在正文解释来源。

4

导出图片：在森林图窗口点击 Save，选择格式与路径。推荐优先矢量格式以便投稿排版：

  • 矢量（清晰可无损放大）：SVG、EPS、PDF、EMF
  • 位图（通用）：PNG
5

纳入正文：右键 Figures → Add Figure → 选择 Forest plot → 指定对应结局 → Finish。之后需在正文相应位置插入对该图的引用，图才会随综述一同输出。

发表提示 多数期刊要求黑白或灰度图，导出后可在矢量软件中统一转为黑白；同时核对图上 “Favours …” 标签与效应量方向一致（见第 05 节红色提示框）。

08偏倚风险图与漏斗图约 15–20 分钟

两项常用辅助图形，分别用于方法学质量评价与发表偏倚初筛。

8.1 偏倚风险图（Risk of Bias）

1

先为每项研究填写 RoB 表：展开 Tables › Risk of bias tables，或右键某研究 → Edit Study characteristics，在 Risk of bias 表内对 7 个条目作 Low / Unclear / High 判定。

2

右键左侧 Figures → Add Figure → 选择 Risk of bias graph（各条目分布条形图）或 Risk of bias summary（逐研究的红黄绿汇总表）→ Finish。

8.2 漏斗图（Funnel Plot）

3

打开某结局的数据表 → 点击 Funnel Plot 按钮即可查看；如需随文发表，同样通过 Add Figure 加入 Figures 节点。

解读边界 漏斗图仅作对称性目测的初筛；Egger 检验、Begg 检验等需借助 Stata / R（如 metafor 包）完成，RevMan 本身不提供。研究结果少于 10 项时，漏斗图检验效能很低，不宜据此下结论。

8.3 敏感性分析

4

在结局数据表中取消勾选某研究前的复选框，即可将其暂时排除出合并分析，用于逐一剔除法的稳健性检验；重新勾选即可恢复，不会删除数据。相关图表会自动更新。

09保存、备份与核查约 5 分钟

1

保存：任何修改即时生效于当前打开的文件；点工具栏 Save 手动保存为本地 .rm5 文件。软件默认每 10 分钟自动备份一次（可在 Tools › Preferences › General 中调整）。

2

版本管理：建议在关键节点（建好框架、录完数据、出完图）另存不同版本文件名，例如 PFO_meta_v1.rm5、v2.rm5，避免误改后无法回溯。

3

提交前核查：菜单 File › Validate（验证）与 Status report（状态报告）可检查缺失项与完整性；逐项核对正文数字与森林图是否一致、亚组与敏感性分析是否已如实描述。

重要 非 Cochrane 模式下全部数据仅存于本机。请务必将 .rm5 文件纳入你的常规备份（如外置盘或网盘），否则一旦磁盘故障将无可恢复的云端副本。

10统计要点与数据规范速查

决策点推荐做法
二分类效应量选 RR 还是 OR事件较常见、需直观解释时优先 RR；稀有事件或病例对照研究可用 OR。全文统一并说明。
连续变量选 MD 还是 SMD各研究使用相同量表与单位用 MD；量表不同或单位不一时用 SMD。
固定 vs 随机效应模型研究间仅存在抽样误差可用固定效应；存在临床或方法学异质性（常以 I² > 50% 为参考）优先随机效应。Cochrane 手册倾向：有临床异质性时即使 I² 不高也可考虑随机效应。
异质性处理先核查数据录入与临床异质性；必要时做预设亚组分析或敏感性分析，并在 Discussion 中解释，不要仅凭统计指标机械决定。
从文献提取数据二分类取事件数与总人数；连续取 mean ± SD 与 n；只报 median (IQR) 时按统计方法估算并标注；生存数据取 HR 与 95%CI 时用 Generic Inverse Variance。
结果与结论一致摘要、正文、森林图三处的效应量、CI、P 值与 I² 必须逐一对应；任何探索性发现须明确标注，不得写成预设结论。

11常见问题排查速查

首次启动后程序闪退或自动退出？

多为首次加载 Java 环境或更新检查触发。本机经实测可正常启动；若遇退出，重新打开即可，通常第二次启动稳定。若反复闪退，检查是否误选 Cochrane 模式导致连接服务器失败——可在偏好设置或 Usage mode 中切回 non-Cochrane。

启动时报无法连接 rm5.cochrane.org / WSDL 错误？

说明当前处于 Cochrane 模式或尝试联网校验。请切换到 non-Cochrane（非 Cochrane）模式离线使用；本机网络访问该域名受限，属正常现象，不影响本地建库与分析。

右键菜单出不来？

Mac 上右键 = Control+单击，或触控板双指点按；也可在辅助设置中开启鼠标右键。

森林图上出现向左 / 向右的箭头？

某研究的置信区间超出了当前横轴范围。拖动图下方的 scale 滑块扩大刻度，直到箭头消失。

从 Excel 粘贴后数据错位或报错？

检查：① Excel 中研究顺序与 RevMan 数据表顺序是否一致；② 列序是否正确（二分类 E/N 的位置；连续型 Mean/SD/N 的位置）；③ 单元格内是否混入文本、空格、全角字符或不规范的减号。确保起始单元格为数据区左上角。

想换结局的数据类型，已有数据怎么办？

右键 outcome → Properties → General 可改 Data type，但更换数据类型会清空已录入的数据。请在录数前确定类型；确需变更时先另存备份。

为什么森林图数据是空的 / 无法计算？

排查顺序：① 综述是否为 Full review（Protocol 不能计算）；② 研究是否已加入 Included studies；③ 研究是否已通过 Add Study Data 挂到该结局下；④ 数据是否完整录入。

结局下想同时挂研究和亚组可以吗？

不可以。一个结局下要么直接包含研究，要么包含亚组（研究放在亚组内）。若已挂研究，可用右键 Introduce Subgroup 将其转入新建亚组。
