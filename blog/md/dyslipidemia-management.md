## 一、血脂化验单，先看哪几项

| 指标 | 理想方向 | 意义 |
| --- | --- | --- |
| LDL-C（低密度脂蛋白胆固醇） | 按分层目标，越低越好 | 致动脉粥样硬化的"主力"，首要干预靶点 |
| TC（总胆固醇） | <5.2 mmol/L | 总体水平参考 |
| TG（甘油三酯） | <1.7 mmol/L | 显著升高（≥5.6）需防急性胰腺炎 |
| HDL-C（高密度脂蛋白胆固醇） | 较高为佳 | "逆向转运"胆固醇，但升高 HDL 的药物获益未获证实 |
| 非 HDL-C | 越低越好 | 涵盖全部致粥样硬化颗粒 |

## 二、干预目标由"危险分层"决定

LDL-C 没有统一的"正常值"，目标因人而异：

| 危险分层 | 人群举例 | LDL-C 目标 |
| --- | --- | --- |
| 低危 | 无危险因素，10 年风险低 | <3.4 mmol/L |
| 中危 | 高血压或多项危险因素 | <2.6 mmol/L |
| 高危 | 糖尿病、慢性肾病、LDL-C ≥4.9 mmol/L | <1.8 mmol/L，且较基线降幅 ≥50% |
| 极高危 | 已确诊冠心病、卒中或外周动脉疾病 | <1.4 mmol/L，且降幅 ≥50% |

> 以上为常用科普口径，具体目标值与起始治疗阈值由医生结合总体心血管风险评估确定。

## 三、生活方式：第一块基石

1. **饮食**：减少饱和脂肪（动物油脂、肥肉、棕榈油）与反式脂肪摄入，增加膳食纤维、全谷物、蔬菜、豆类与鱼类；
2. **运动**：每周 ≥150 分钟中等强度有氧运动，辅以抗阻训练；
3. **体重**：超重/肥胖者减重 5%–10% 即可显著改善血脂；
4. **戒烟限酒**：吸烟降低 HDL-C 并损伤血管；酒精升高 TG；
5. **限糖**：精制糖与含糖饮料显著升高 TG。

## 四、药物治疗的阶梯

- **他汀类（首选）**：辛伐他汀、阿托伐他汀、瑞舒伐他汀等，剂量倍增可使 LDL-C 进一步下降约 6%；
- **胆固醇吸收抑制剂**：依折麦布，与他汀联用实现"双通道"阻断；
- **PCSK9 抑制剂**：依洛尤单抗等注射制剂，用于他汀/依折麦布仍不达标的极高危患者；
- **贝特类 / 高纯度 ω-3**：以 TG 显著升高为主要问题时选用；
- **随访与安全**：开始他汀后 4–6 周复查血脂、肝酶与肌酶；多数人耐受良好，出现肌肉酸痛等症状应及时与医生沟通，而非直接停药。

一段模拟的危险分层决策逻辑：

```
输入：男，58 岁，吸烟，BP 132/80 mmHg（未治疗），HDL-C 1.0 mmol/L
标记：年龄 ≥45 岁（+1），吸烟（+1），HDL-C 偏低（+1）
合并症：陈旧性心肌梗死 → 判定为"极高危"
LDL-C 目标：<1.4 mmol/L 且较基线下降 ≥50%
策略：高强度他汀起始；4–6 周复查；未达标者联合依折麦布
```

## 五、常见误区

- **瘦人不会血脂高**：遗传与代谢因素同样致病，体型不是保护伞；
- **血脂正常就停药**：达标是"管"出来的，停药后多会回升；
- **只靠食疗拒绝用药**：显著升高或高危/极高危者，必须药物干预；
- **忽视甘油三酯**：重度升高有急性胰腺炎风险，且常伴代谢综合征。

> **医学提示：** 调脂治疗是长期过程，目标值与用药强度由医生根据危险分层制定。首次用药或调整剂量后，请按医嘱复查血脂、肝酶与肌酶。
