## 一、高血压的诊断标准

在未使用降压药物的情况下，非同日 3 次测量诊室血压，收缩压 ≥140 mmHg 和（或）舒张压 ≥90 mmHg，即可诊断为高血压。家庭自测血压的诊断阈值为 ≥135/85 mmHg。

> **提示：** 一次测量升高不能确诊，也无需过度紧张——情绪、运动、咖啡因都会造成暂时性升高。

## 二、血压分级（诊室标准）

| 分级       | 收缩压（mmHg） | 舒张压（mmHg）   |
| -------- | --------- | ----------- |
| 正常血压     | <120      | 且 <80       |
| 正常高值     | 120–139   | 和（或）80–89   |
| 1 级（轻度）  | 140–159   | 和（或）90–99   |
| 2 级（中度）  | 160–179   | 和（或）100–109 |
| 3 级（重度）  | ≥180      | 和（或）≥110    |
| 单纯收缩期高血压 | ≥140      | 且 <90       |

分级由较高的那一侧定级——例如 150/105 mmHg 属于 2 级。

## 三、危险分层：比"数字"更重要

同样的血压，风险可以完全不同。临床分层综合三方面：

- **心血管危险因素**：年龄、吸烟、血脂异常、糖尿病、肥胖、早发心血管病家族史等；
- **靶器官损害**：左心室肥厚、颈动脉斑块、eGFR 降低、蛋白尿等；
- **临床合并症**：冠心病、卒中/短暂性脑缺血、心力衰竭、慢性肾病、糖尿病、外周动脉疾病等。

| 危险分层 | 含义                              |
| ---- | ------------------------------- |
| 低危   | 1 级高血压，无其他危险因素                  |
| 中危   | 1 级伴 1–2 个危险因素，或 2 级伴少数危险因素     |
| 高危   | 3 级，或 1–2 级伴 ≥3 个危险因素/靶器官损害/糖尿病 |
| 很高危  | 任一级别合并临床合并症，或 3 级伴 ≥1 个危险因素     |

## 四、治疗目标与手段

- **一般人群**：<140/90 mmHg，能耐受者可进一步降低；
- **合并糖尿病、慢性肾病、冠心病等高危人群**：多数建议 <130/80 mmHg（需个体化，由医生把握）；
- **老年患者**：目标适当放宽、降压宜缓，避免过快过低。

治疗采用"生活方式 + 药物"双轨：

1. **生活方式是地基**：限盐（<5 克/天）、控制体重、规律运动、戒烟限酒、均衡饮食、管理情绪与睡眠；
2. **药物治疗**：常用五类——CCB、ACEI、ARB、噻嗪类利尿剂、β 受体阻滞剂，可单药起始或小剂量联合；
3. **优先联合治疗**：多数 2 级及以上患者，起始即小剂量联合用药，降压效果更好、副作用更少；
4. **长效制剂优先**：优先选择 24 小时平稳降压的长效药物，提高依从性、减少晨峰血压波动。

## 五、随访与记录

确诊后应规律随访，评估血压达标、药物副作用与靶器官变化。一份简明的随访记录可以这样维护：

```
日期：2026-10-16
诊室血压：146/92 mmHg（右上肢，坐位，休息 5 分钟后）
用药：氨氯地平 5 mg qd
心率：72 次/分
评估：1 级高血压，未达标（目标 <140/90）
计划：4 周后复查；已嘱限盐、减重，家庭自测血压每日 2 次并记录
```

## 六、常见误区

- **没症状就不用管**：高血压大多无症状，损害却在持续；
- **血压正常就停药**：降压药是"控制"不是"治愈"，擅自停药容易反弹；
- **越降越快越好**：除高血压急症外，应平稳、缓慢降压；
- **只信偏方不信药**：任何"降压食物/保健品"都不能替代规范治疗。

> **医学提示：** 本文为健康科普，血压分级与用药需由医生结合完整评估确定。若血压 ≥180/120 mmHg 并伴头痛、胸闷、视物模糊等症状，请立即就医。
