## 一、先弄清两个问题

面对心律失常，医生先问两个问题：**心率快还是慢？激动从哪来？** 前者决定紧急程度，后者提示病灶位置与治疗策略。

## 二、按心率快慢分类

| 大类 | 常见类型 | 简要说明 |
| --- | --- | --- |
| 心动过速 | 窦性心动过速 | 多为生理或代偿反应 |
| | 房性早搏、房性心动过速 | 起源于心房 |
| | 心房颤动（房颤） | 最常见，脑卒中风险的重要来源 |
| | 心房扑动 | 常与房颤并存 |
| | 阵发性室上速 | 突发突止，多位于房室交界区 |
| | 室性早搏、室性心动过速 | 起源于心室，风险相对更高 |
| | 心室颤动 | 心脏骤停的主要原因，需立即除颤 |
| 心动过缓 | 窦性心动过缓、窦性停搏 | 可为生理性（运动员）或病理性 |
| | 房室传导阻滞 | 分 Ⅰ/Ⅱ/Ⅲ 度，Ⅲ 度常需起搏 |
| | 病态窦房结综合征 | 快慢交替，常需起搏治疗 |

## 三、按激动起源分类

- **窦性心律失常**：起源正常（窦房结），仅频率或节律变化；
- **房性心律失常**：起源心房，包括房早、房速、房颤、房扑；
- **室性心律失常**：起源心室，包括室早、室速、室颤；
- **房室交界区相关**：交界性心律、阵发性室上速。

## 四、处理原则：从"观察"到"干预"

并非所有心律失常都需要治疗。策略按风险分层：

1. **无需治疗、观察随访**：无症状的窦性心律不齐、偶发房早/室早、无器质性心脏病的良性早搏——定期复查即可；
2. **去除诱因 + 对症**：纠正缺氧、电解质紊乱（尤其低钾、低镁）、甲状腺功能亢进、贫血，停用刺激性物质（如过量咖啡因）；
3. **药物治疗**：控制心室率（β 阻滞剂、非二氢吡啶类 CCB、地高辛）、抗心律失常药（普罗帕酮、胺碘酮等，需权衡获益与副作用）以及抗凝（房颤者按 CHA₂DS₂-VASc 评分决策）；
4. **导管消融**：阵发性室上速、典型房扑、症状性房颤、部分室早/室速的首选根治手段；
5. **器械治疗**：起搏器用于有症状的心动过缓；ICD 用于高危室性心律失常的一级/二级预防。

## 五、出现这些情况，立即急诊

- 意识丧失、抽搐（晕厥或阿斯发作）；
- 持续胸痛伴心悸、大汗；
- 心率持续 >150 次/分或 <40 次/分且伴症状；
- 黑朦、明显气短、血压下降。

## 六、一份心电图初判清单

```
1. 看心率：数 6 秒内的 R 波 ×10，是否 <60 或 >100
2. 看节律：RR 间期是否匀齐，有无早搏或长间歇
3. 看 P 波：形态是否正常，与 QRS 是否相关
4. 看 QRS：宽（≥0.12 秒，提示室性来源）还是窄（室上性来源）
5. 看 ST-T：有无缺血或梗死图形

结论示例：RR 绝对不齐 + 无 P 波 + 窄 QRS → 提示心房颤动
```

> **医学提示：** 心电图只是"快照"，阵发性心律失常常需动态心电图（Holter）、事件记录仪甚至电生理检查才能捕获。诊断与治疗方案请由医生确定。
